# Regional Running Races & Trails for Home Assistant 🏅📅

[![HACS Custom Repository](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://hacs.xyz/)
[![Home Assistant](https://img.shields.io/badge/Home--Assistant-2024.1+-blue.svg)](https://www.home-assistant.io/)

A Home Assistant integration that provides a native **Calendar entity** and **Next Race sensor** for regional official running competitions (10k, Half-Marathons, Marathons, Trails, and Urban Trails).

---

## ✨ Features
- 📅 **Native Calendar (`calendar.running_races_<dept>`)**: Displays all upcoming running competitions in your department/region.
- 🎯 **Next Target Race Sensor**: Displays the countdown (days remaining), distance, elevation gain, location, and registration link for the next race.

---

## 🚀 Installation via HACS
1. In Home Assistant, open **HACS** > **Integrations** > **Custom repositories**.
2. Add this repo URL with category **Integration**.
3. Download and restart Home Assistant.
4. Go to **Settings** > **Devices & Services** > **Add Integration** > **Running Races**.
